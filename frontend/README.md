# CommuteCare 프론트엔드

출퇴근 도우미 챗봇의 React 프론트엔드 애플리케이션입니다.

## 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm start
```

애플리케이션이 [http://localhost:3000](http://localhost:3000)에서 실행됩니다.

### 3. 빌드
```bash
npm run build
```

프로덕션용 빌드를 `build` 폴더에 생성합니다.

## 환경 변수

프로젝트 루트에 `.env` 파일을 생성하여 환경 변수를 설정할 수 있습니다:

```env
REACT_APP_API_URL=http://localhost:8001
```

## 주요 기능

### 💬 채팅 인터페이스
- 실시간 채팅 UI
- 사용자 메시지와 봇 응답 구분
- 자동 스크롤 기능

### 🚇 지하철 정보 조회
- 역 이름 기반 실시간 도착정보
- 자연어 질문 처리
- 다중 역 정보 조회 지원

### 📱 반응형 디자인
- 모바일 최적화
- 태블릿 및 데스크톱 지원
- 터치 친화적 인터페이스

### 🎨 현대적 UI/UX
- 그라데이션 색상 테마
- 부드러운 애니메이션
- 직관적인 사용자 경험

## 기술 스택

- **React** 18.2.0
- **Axios** - HTTP 클라이언트
- **Lucide React** - 아이콘
- **CSS3** - 스타일링

## 컴포넌트 구조

```
src/
├── App.js          # 메인 애플리케이션 컴포넌트
├── App.css         # 메인 스타일
├── index.js        # React 진입점
└── index.css       # 전역 스타일
```

## API 연동

백엔드 API와 연동하여 다음 기능을 제공합니다:

- `POST /chat` - 챗봇 대화 처리
- `GET /stations/{station_name}` - 역별 정보 조회
- `GET /health` - 서버 상태 확인

## 사용법

1. 웹 브라우저에서 애플리케이션 접속
2. 입력창에 지하철 관련 질문 입력
   - 예: "강남역 도착정보 알려줘"
   - 예: "홍대입구역 언제 와?"
3. 실시간 도착정보 확인

## 예시 질문

- "강남역 도착정보 알려줘"
- "홍대입구역 언제 와?"
- "신촌역 실시간 정보"
- "건대입구역 지하철 정보"

## 문제 해결

1. **서버 연결 오류**: 백엔드 서버가 실행 중인지 확인
2. **API 응답 없음**: 백엔드 환경변수 설정 확인
3. **스타일 깨짐**: 브라우저 캐시 삭제 후 새로고침
